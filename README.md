# 🩺 شفاء AI — Shefa AI
### المساعد الصيدلي الذكي للتقييم المبدئي للأعراض واختيار العلاج الآمن
**مشروع تخرج — كلية الصيدلة، جامعة القاهرة**

شات بوت بالعامية المصرية بيسمع شكوى المريض، ويسأله أذكى الأسئلة، ويطلع تشخيص تفريقي مبدئي بالاحتمالات،
وبعدين يختار العلاج المناسب بدون روشتة (OTC) **بعد ما يفحص** موانع الاستعمال والتداخلات الدوائية وسن المريض،
ويقرر إمتى لازم يتحول للدكتور أو للطوارئ فوراً.

---

## 🌐 الطريقة الأولى: لينك أونلاين (للمشاركة على واتساب) — مجاناً
بتعملها **مرة واحدة** وبعدها أي حد يفتح اللينك من الموبايل أو الكمبيوتر من غير ما يسطب أي حاجة.
1. افتح https://share.streamlit.io ودوس **Continue with GitHub** وادخل بحسابك (Roses-79) ووافق على الصلاحيات.
2. دوس **Create app** ← وبعدين **Deploy a public app from GitHub**.
3. املا الخانات:
   - **Repository:** `Roses-79/shefa-ai`
   - **Branch:** `main`
   - **Main file path:** `app.py`
   - **App URL:** اكتب اسم سهل زي `shefa-ai` (لو محجوز جرب `shefa-ai-cairo`)
4. دوس **Deploy** واستنى 2-3 دقايق.
5. هيطلعلك لينك زي `https://shefa-ai.streamlit.app` ← ده اللي تبعته على الجروب.

> لو حد فتح اللينك بعد فترة طويلة ولقى "This app has gone to sleep" يدوس على **Yes, get this app back up** ويستنى دقيقة.

## 💻 الطريقة التانية: تشغيله على الكمبيوتر (للعرض — شغال من غير نت)

### أول مرة بس (محتاجة نت)
1. **نزّل بايثون:** ادخل https://www.python.org/downloads/ ودوس الزرار الأصفر الكبير **Download Python**.
   وانت بتسطب: ✅ **علّم على "Add python.exe to PATH"** (تحت خالص في أول شاشة) وبعدين **Install Now**.
2. **نزّل المشروع:** ادخل https://github.com/Roses-79/shefa-ai ← دوس الزرار الأخضر **Code** ← **Download ZIP**.
3. **فك الضغط:** كليك يمين على الملف اللي نزل ← **Extract All** ← **Extract**. (متشغلش من جوه الـ ZIP)
4. **شغّل:** افتح الفولدر اللي اتفك ودبل كليك على **`run_windows.bat`**.
   - لو ويندوز طلّع شاشة زرقا "Windows protected your PC" دوس **More info** ← **Run anyway**.
   - هيفتح شباك أسود يسطب المكتبات (دقيقة أو اتنين أول مرة بس)، وبعدين البرنامج هيفتح لوحده في المتصفح.

### كل مرة بعد كده
دبل كليك على **`run_windows.bat`** ← البرنامج يفتح (من غير نت).
⚠️ **سيب الشباك الأسود مفتوح** طول ما انت شغال على البرنامج. لما تخلص اقفله.

**ماك:** افتح Terminal واكتب `bash ` (بمسافة) واسحب ملف `run_mac_linux.sh` جوه الشباك ودوس Enter.

### لو حصلت مشكلة
| المشكلة | الحل |
|---|---|
| الشباك الأسود بيقول Python is not installed | سطّب بايثون تاني وعلّم على **Add python.exe to PATH** |
| المتصفح مفتحش لوحده | افتح Chrome واكتب `localhost:8501` |
| Installing failed | اتأكد إن النت شغال وجرب تاني |
| البرنامج وقف/علّق | اقفل الشباك الأسود وافتح `run_windows.bat` تاني |

### للمطورين (اختياري)
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
python -m unittest discover tests -v     # الاختبارات
```

### (اختياري) تفعيل الذكاء الاصطناعي التوليدي Claude
البرنامج شغال **كامل من غير أي مفتاح**. لو عاوز تضيف طبقة Claude: اعمل API key من https://console.anthropic.com وحطه في خانة **Anthropic API Key** في الشريط الجانبي.

## 📁 هيكل المشروع
```
shefa-ai/
├── app.py                  ← واجهة المستخدم (Streamlit)
├── engine/
│   ├── knowledge_base.py   ← قاعدة المعرفة: الأعراض، الحالات، الأدوية، التداخلات، علامات الخطر
│   ├── nlp.py              ← فهم اللغة العربية (Normalization + Negation + Extraction)
│   ├── diagnosis.py        ← محرك Bayes + Information Gain + Explainability
│   ├── safety.py           ← موانع الاستعمال + التداخلات + جرعات الأطفال + قواعد التحويل
│   ├── ai_assistant.py     ← طبقة Claude الاختيارية
│   └── report.py           ← تقرير المريض
├── tests/test_engine.py    ← 24 اختبار + 14 حالة إكلينيكية افتراضية
├── docs/BOOK_AR.md         ← كتاب المشروع (الشرح الكامل للمناقشة)
├── run_windows.bat         ← تشغيل بدبل كليك
└── requirements.txt
```
