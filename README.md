# 🩺 شفاء AI — Shefa AI
### المساعد الصيدلي الذكي للتقييم المبدئي للأعراض واختيار العلاج الآمن
**مشروع تخرج — كلية الصيدلة، جامعة القاهرة**

شات بوت بالعامية المصرية بيسمع شكوى المريض، ويسأله أذكى الأسئلة، ويطلع تشخيص تفريقي مبدئي بالاحتمالات،
وبعدين يختار العلاج المناسب بدون روشتة (OTC) **بعد ما يفحص** موانع الاستعمال والتداخلات الدوائية وسن المريض،
ويقرر إمتى لازم يتحول للدكتور أو للطوارئ فوراً.

---

## ⚡ التشغيل (خطوات كوبي-بيست)

### الخطوة 0 — نزّل بايثون (مرة واحدة بس)
- ادخل على https://www.python.org/downloads/ ونزّل Python 3.10 أو أحدث.
- **مهم جداً في ويندوز:** وانت بتسطب علّم على ✅ **Add Python to PATH**.

### الخطوة 1 — افتح التيرمنال جوه فولدر المشروع
- **ويندوز:** افتح فولدر `shefa-ai`، اكتب `cmd` في شريط العنوان فوق ودوس Enter.
- **ماك/لينكس:** افتح Terminal واكتب `cd ` واسحب الفولدر جوه الشباك ودوس Enter.

### الخطوة 2 — سطّب المكتبات (مرة واحدة بس)
```bash
python -m pip install -r requirements.txt
```
> على ماك لو `python` مش شغال استخدم `python3` بدلها.

### الخطوة 3 — شغّل البرنامج
```bash
python -m streamlit run app.py
```
البراوزر هيفتح لوحده على `http://localhost:8501` 🎉

**أسهل طريقة في ويندوز:** دبل كليك على `run_windows.bat` وهو هيعمل الخطوتين 2 و 3 لوحده.
**ماك/لينكس:** `./run_mac_linux.sh`

### (اختياري) تشغيل الاختبارات
```bash
python -m unittest discover tests -v
```

### (اختياري) تفعيل الذكاء الاصطناعي التوليدي Claude
البرنامج شغال **كامل من غير إنترنت ومن غير أي مفتاح**. لو عاوز تضيف طبقة Claude (فهم أعمق للكلام الحر + شرح ودود):
1. اعمل حساب على https://console.anthropic.com واعمل API key.
2. حطه في خانة **Anthropic API Key** في الشريط الجانبي جوه البرنامج.

## 📁 هيكل المشروع
```
shefa-ai/
├── app.py                  ← واجهة المستخدم (Streamlit)
├── engine/
│   ├── knowledge_base.py   ← قاعدة المعرفة: الأعراض، الحالات، الأدوية، التداخلات، علامات الخطر
│   ├── nlp.py              ← فهم اللغة العربية (Normalization + Negation + Extraction)
│   ├── diagnosis.py        ← محرك Bayes + Information Gain + Explainability
│   ├── safety.py           ← موانع الاستعمال + التداخلات + جرعات الأطفال + قواعد التحويل
│   ├── ai_assistant.py     ← طبقة Claude الاختيارية
│   └── report.py           ← تقرير المريض
├── tests/test_engine.py    ← 24 اختبار + 14 حالة إكلينيكية افتراضية
├── docs/BOOK_AR.md         ← كتاب المشروع (الشرح الكامل للمناقشة)
├── run_windows.bat         ← تشغيل بدبل كليك
└── requirements.txt
```
